Number Analyzer

A simple command-line number analyzer written in Python.

Features

* Find the maximum and minimum numbers
* Calculate the sum of all numbers
* Calculate the arithmetic mean
* Count positive and negative numbers
* Count zeros
* Validate the requested number count

Technologies

* Python 3
* Standard Python library (no external dependencies)

How to Run

1. Install Python 3.
2. Download analyzer.py.
3. Open a terminal in the folder containing the file.
4. Run:
    python analyzer.py
5. Enter the number of integers you want to analyze and follow the prompts.

Example

Input:

Enter number count: 3
Enter first number: 6
Enter number: -2
Enter number: 4

Results:

Maximum: 6
Minimum: -2
Sum: 8
Average: 2.6666666666666665
Positive numbers: 2
Negative numbers: 1
Zeros: 0

Note: The current program displays prompts and results in Russian.
